# S01 — Project scaffold: deployable Worker skeleton

**Epic:** scaffolding · **Depends on:** nothing · **Spec refs:** [08-tech-stack](../specs/08-tech-stack.md), [01-architecture](../specs/01-architecture.md)

> As a developer, I want a typed, tested, manually-deployable Worker skeleton, so that every later story lands on rails instead of yak-shaving.

## Description

The repo becomes a working TypeScript Cloudflare Worker project with the exact version pins, config shapes and directory layout from spec 08: `wrangler.jsonc` (assets binding, KV, both cron expressions, `BASE_URL` var), Hono entry point with `/api/health` and an empty cron dispatcher, the two-project vitest setup (unit + workers pool, **post-0.13 API**), generated `Env` types, and the secret/`.dev.vars` convention. Ends with the first real manual deploy.

## Acceptance criteria

- [ ] `package.json` pins the spec-08 versions; `npm install` is clean on Node 22 LTS; `npm run check` (tsc + both vitest projects) and `npm test` scripts exist.
- [ ] `wrangler.jsonc` matches the spec-08 shape: `run_worker_first: ["/api/*", "/mcp", "/mcp/*"]`, `ASSETS` + `KV` bindings, both cron triggers, `BASE_URL` var, `nodejs_compat`; `worker-configuration.d.ts` generated by `wrangler types` and committed.
- [ ] `src/` skeleton follows the spec-01 tree (empty `core/ports/adapters/delivery/jobs` directories may hold only placeholder modules); `src/index.ts` exports `fetch` (Hono) and `scheduled` (dispatcher keyed by cron expression) as `satisfies ExportedHandler<Env>`.
- [ ] One unit-project test passes (trivial pure function) and one worker-project test passes: `GET /api/health` via `exports.default.fetch` returns `{ ok: true }`, and a KV put/get round-trips via `env.KV` — proving the pool, bindings and config path all work.
- [ ] A worker-project test invokes the scheduled handler via `createScheduledController` without error (dispatcher runs, does nothing yet).
- [ ] `.dev.vars` is git-ignored and documented; no secret value appears anywhere in the repo.
- [ ] **First manual deploy performed**: `wrangler deploy` succeeds; `https://tjaldur.<account>.workers.dev/api/health` returns 200 `{ ok: true }`; the URL is recorded in this story's notes and set as `BASE_URL`.

## Demo

Clone → `npm install` → `npm run check` green → `npx wrangler deploy` → `/api/health` live on workers.dev.
